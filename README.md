# وب‌سایت پورتفولیو شخصی

این پروژه یک وب‌سایت پورتفولیوی چندصفحه‌ای، مدرن و کاملاً ریسپانسیو است که برای نمایش مهارت‌ها، رزومه و پروژه‌های دانشگاهی و کاری من طراحی و پیاده‌سازی شده است.

## ویژگی‌های پروژه
- طراحی مدرن با تم تاریک (Dark Mode) و المان‌های بصری جذاب
- ساختار چندصفحه‌ای منظم (Multi-Page Website)
- طراحی کاملاً ریسپانسیو (Responsive) و بهینه‌سازی شده برای موبایل، تبلت و دسکتاپ
- استفاده از JavaScript برای ایجاد تعاملات و انیمیشن‌های کاربردی (دکمه بازگشت به بالا)
- مجهز به فرم تماس با من و راه‌های ارتباطی مستقیم
